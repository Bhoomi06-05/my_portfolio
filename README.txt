BHOOMI SHARMA — PORTFOLIO WEBSITE

Files:
- index.html: responsive portfolio website
- profile.jpg: add your own profile photo here
- resume.pdf: add your latest resume PDF here

Before publishing:
1. Copy your chosen profile photo into this folder and name it profile.jpg.
2. Copy your latest resume PDF into this folder and name it resume.pdf.
3. Open index.html in a browser to preview.
4. Update the LinkedIn and email contact section in index.html with your real public details.
5. Publish the folder using GitHub Pages:
   - Create a public GitHub repository (e.g. bhoomi-portfolio).
   - Upload index.html, profile.jpg and resume.pdf.
   - In repository Settings > Pages, choose Deploy from a branch, select main and / (root), then Save.
   - Wait for GitHub Pages to provide your public website URL.

The website uses only HTML and CSS; no build tools are required.
